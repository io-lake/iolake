# IOLake brand assets

Mark: **Strata**, a disc of five layers: two of ink above the waterline and three of teal below, the lake. In the horizontal logo the disc is the "O" of IOLake. Never rotate it, change its layers or recolor it; keep the waterline horizontal.

```
iolake-mark.svg, iolake-mark-on-dark.svg                     the disc alone, for light and dark grounds
iolake-logo-horizontal.svg, iolake-logo-horizontal-on-dark.svg   primary logo, type outlined (Sora 600; no font needed)
iolake-logo-stacked.svg, iolake-logo-stacked-on-dark.svg     the disc above the name
favicon.svg                                                   browser tab (the disc on an ink square)
app-icon.svg                                                  512 rounded-square icon
readme-banner.svg, readme-banner.png, readme-banner-2x.png   1280×320 header (and 2560×640)
brand-tokens.css, brand-tokens.json                           colors and font stacks
```

Colors: ink #0e1f26 · depth #1d3038 · slate #5b6e74 · mist #c9d6d8 · paper #f3f6f6
        lake #11666f · lake-bright #2a9d8f · lake-light #4cc3b6 · shallows #e3f1f0
Fonts:  Sora 600 (wordmark, headings) · IBM Plex Sans (body) · IBM Plex Mono (code)

Clear space: a quarter of the disc's height on every side. Smallest size: 16 px for the disc, 96 px wide for the horizontal logo.

README usage:

```html
<p align="center"><img src="assets/readme-banner.png" width="100%" alt="IOLake"></p>
```

The full brand book (colors in both themes, type scale, spacing, usage rules) is the IOLake design system.
